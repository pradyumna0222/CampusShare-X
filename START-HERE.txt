CAMPUSSHARE X — FULL-STACK APPLICATION (WINDOWS)

IMPORTANT: This is the server-backed React + Express application, not the old standalone HTML demo.

1. Extract CampusShare-X-Final.zip to a folder.
2. Open PowerShell in the extracted folder that directly contains package.json.
3. Run: Get-ChildItem package.json
   If PowerShell cannot find package.json, you are in the wrong folder. Move to the folder containing package.json before continuing.
4. Run: Copy-Item .env.example .env
5. If a previous install failed, stop Node processes and remove partial node_modules first (see docs/WINDOWS_INSTALL_FIX.md).
6. Run: npm install
7. Run: npm run dev
8. Open: http://localhost:5173
