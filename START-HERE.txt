CAMPUSSHARE X — FULL-STACK APPLICATION (POSTGRESQL + NEON READY)

IMPORTANT: This is the server-backed React + Express + PostgreSQL application with Neon Free & Render Free deployment support.

1. Open PowerShell in the project directory that contains package.json.
2. Run: Get-ChildItem package.json
3. Run: Copy-Item .env.example .env
4. Run: npm install
5. Run: npm run migrate
6. Run: npm run dev
7. Open: http://localhost:5173

Local starter accounts (for local development & testing):
Student:   student@campusshare.local / CampusStudent!2026
Student 2: student2@campusshare.local / CampusStudent2!2026
Owner:     owner@campusshare.local / CampusOwner!2026
Admin:     admin@campusshare.local / CampusAdmin!2026

Verification suite:
  npm test
  npm run typecheck
  npm run build

Data persistence:
Local runs use embedded PostgreSQL (PGlite) or your DATABASE_URL in .env.
Production deployment uses Neon Free PostgreSQL via DATABASE_URL on Render Free web service.

See README.md for exact step-by-step commands to create the free Neon database, deploy to Render Free, and connect your custom .xyz domain.
